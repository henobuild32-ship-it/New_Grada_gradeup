# Guide utilisateur GradeUp

Ce guide décrit les actions disponibles dans l'application. Les libellés peuvent varier selon la configuration de l'établissement.

## Administration

- **Utilisateurs** : créer ou modifier des comptes, renseigner les champs requis, affecter une classe, importer un CSV après aperçu et corriger les lignes en erreur.
- **Classes et cours** : attribuer un titulaire, des enseignants et les coefficients selon les règles de l'école.
- **Horaires** : sélectionner une classe, ajouter ou modifier des créneaux; sur ordinateur glisser un cours vers une case vide; sur mobile utiliser « Modifier ». Les conflits refusés affichent les éléments à corriger.
- **Finances** : choisir élève, devise et tranche; vérifier le reçu; les paiements sensibles nécessitent une connexion.
- **Bulletins** : examiner les transmissions du titulaire, ajuster l'appréciation, valider puis publier. La publication est en ligne uniquement.
- **Présences** : utiliser QR caméra si le navigateur l'autorise, ou saisir le matricule; sans réseau, la file est synchronisée ensuite.
- **Notifications/Gradie** : cibler école, rôle, classe ou utilisateur. Les signaux IA orientent le suivi et ne remplacent pas une décision pédagogique.

## Professeur

- Consulter les cours/classes affectés; faire l'appel et synchroniser au retour du réseau.
- Dans **Leçons**, saisir le contenu en Markdown; le brouillon texte est conservé sur cet appareil. Publier exige une connexion. Les fichiers doivent avoir fini leur téléversement.
- Créer des devoirs, consulter les copies et enregistrer note/commentaire.
- Saisir les notes en respectant maximum et période ouverte.
- Comme titulaire, générer les brouillons de bulletins, relire les notes et l'appréciation, puis transmettre à la direction.

## Élève

- Consulter cours, leçons, devoirs, notes, présence, horaires et notifications.
- Les bulletins ne sont visibles qu'après publication par l'administration. Télécharger le PDF pour le conserver hors ligne.
- Les dépôts en attente affichent leur état; synchroniser dès que la connexion revient.
- Gradie requiert une connexion pour répondre.

## Parent

- Choisir l'enfant dans le sélecteur; la sélection est conservée sur l'appareil.
- Consulter notes, bulletins publiés, reçus, échéancier et présence.
- Télécharger bulletin/reçu pour les rouvrir hors ligne; partager depuis un téléphone si Web Share est disponible.
- Une justification d'absence doit être envoyée/synchronisée pour apparaître au personnel de l'école.

## Connexion, confidentialité et assistance

- Ne partagez pas votre code d'accès ou code parent; connectez-vous avec votre compte personnel.
- Les fonctions nécessitant paiement, publication, validation, gestion des comptes ou clôture annuelle doivent être utilisées en ligne.
- En cas d'erreur, conserver le message affiché et contacter l'administrateur de l'établissement.
